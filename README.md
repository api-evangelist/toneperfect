TonePerfect offers an AI‑powered pronunciation assessment API for language learning applications. It supports ten languages and provides a single endpoint that returns a detailed score (0‑100) for the whole sentence, each word, and individual sounds, including tone information for Mandarin. The service includes free tier credits, transparent pricing, and robust error handling, making it suitable for developers integrating speech evaluation into apps.

**Areas:** Company · Artificial Intelligence · Speech · Language Learning · Pronunciation
